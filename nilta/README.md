# Nilta – Organização Financeira
Publicar em www.setasolucoes.com.br/nilta

1. Google Planilhas > nova planilha > Extensões > Apps Script.
2. Cole nilta_planilha.gs, salve, rode `criarPlanilhaNilta` e autorize.
3. Compartilhar > "Qualquer pessoa com o link" > copie o link.
4. No index.html troque `COLE_AQUI_O_LINK_DA_PLANILHA` pelo link.
5. Suba a pasta `nilta/` no GitHub e publique.

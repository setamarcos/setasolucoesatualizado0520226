# Nilta – Meu dia no volante (v2)
1. Abra a planilha > Extensões > Apps Script > cole nilta_planilha.gs > Salvar.
2. Rode a função `configurar` (autorize).
3. Implantar > Gerenciar implantações > lápis > Versão: Nova versão > Implantar (Executar como: Eu; Acesso: Qualquer pessoa). O link /exec continua o mesmo.
4. Suba index.html + nilta_consultoria.pdf na pasta /nilta do GitHub.
Os dados ficam salvos no celular e vão para a planilha. Mesma data = substitui (não duplica).
